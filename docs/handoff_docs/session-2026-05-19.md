## Call Architecture
```
call_inbound  → create row: session_id=UUID, retell_call_id=NULL; phone lookup → set matched_customer_id
call_started  → findActiveByCallerAndTenant (DESC) → setRetellCallId(session.sessionId, realCallId)
fn/*          → getInboundCall(retellCallId) [fast] → fallback caller lookup; all updates use session.sessionId
call_ended    → getInboundCall(callId) → setCallStatus(session.sessionId, disconnectionReason) → fallback
```
